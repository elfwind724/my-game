# 冯以琳的换装小世界

一个 Three.js + Vite + TypeScript 的 3D 换装互动开放世界小游戏原型。

## 已实现

- Q 版主角“冯以琳”
- 第三人称自由探索
- 多套可爱服饰、帽子、鞋子、翅膀换装
- NPC 对话
- 隐藏道具收集
- 任务系统
- 成就系统
- localStorage 本地存档
- 无外部美术资产依赖，全部用 Three.js 基础几何体生成

## 本地运行

```bash
cd yilintopia-three-dressup
npm install
npm run dev
```

然后打开 Vite 输出的本地地址。

## 操作

- `WASD` 或方向键：移动
- `E`：对话 / 收集
- 右上角按钮：换装、任务、重置存档
